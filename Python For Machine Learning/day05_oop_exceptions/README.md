# Day 5 — Object-Oriented Programming & Exception Handling

Introduces classes, objects, and inheritance, then applies them in two small
JSON-backed applications, alongside exception and file handling.

| Notebook | Description |
|----------|-------------|

| [02_exception_and_file_handling.ipynb](02_exception_and_file_handling.ipynb) | `try`/`except`, custom exceptions, and reading/writing files. |
