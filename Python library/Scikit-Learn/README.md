# scikit-learn

An end-to-end classification workflow using scikit-learn's built-in Iris dataset.

| Notebook | Description |
|----------|-------------|
| [01_complete_workflow.ipynb](01_complete_workflow.ipynb) | Loading data, train/test split, cross-validation, model training, and evaluation — the full scikit-learn workflow in one pass. |

No external data files are required — the notebook uses `sklearn.datasets.load_iris`.
