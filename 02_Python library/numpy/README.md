# NumPy

Core array programming with NumPy: creation, indexing, broadcasting, and
performance comparisons against plain Python loops.

| Notebook | Description |
|----------|-------------|
| [01_numpy_basics.ipynb](01_numpy_basics.ipynb) | Creating arrays, shapes, dtypes, indexing, and slicing. |
| [02_numpy_advanced.ipynb](02_numpy_advanced.ipynb) | Vectorization vs. Python loops, broadcasting, and performance. |
| [03_array_attributes.ipynb](03_array_attributes.ipynb) | Array attributes (`shape`, `ndim`, `size`, `dtype`, etc.) in depth. |

No external data files are required — all examples generate their own arrays.
