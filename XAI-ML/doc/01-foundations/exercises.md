# Exercises — 01 Foundations

1. **Concept check.** In your own words, define the "black box problem." Give one example of a model type that is a black box and one that is not.
2. **Trade-off.** Explain why "Interpretability ∝ 1/Complexity" is described as *the* fundamental law of XAI. Can you think of a counterexample — a highly complex model that is still interpretable, or a simple model that isn't?
3. **DARPA framework.** List the four key components of the DARPA XAI framework and describe, for a loan-approval model, what each component would output.
4. **Taxonomy — timing.** What is the difference between an *antecedent* and a *post-hoc* explanation method? Give two examples of each.
5. **Taxonomy — scope.** A bank wants to know (a) which features drive loan decisions overall, for a regulatory audit, and (b) why one specific applicant was rejected. Which scope (global/local) fits each need, and name one method for each.
6. **Applied.** Pick a real system you interact with (e.g. a recommendation feed, spam filter, credit score). Classify it as glass-box or black-box, and explain what kind of explanation (local/global, model-specific/agnostic) would be most useful to you as an end user.
