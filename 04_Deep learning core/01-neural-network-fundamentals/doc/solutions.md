2. (a) House price — **linear/no activation** (or identity) on the output, since price is an unbounded continuous value, not a probability. (c) 10-digit classification — **Softmax**, since we need a probability distribution over 10 mutually exclusive classes that sums to 1.

3. If a ReLU neuron's weighted input `z` is negative for every example in the training set (e.g. due to unlucky initialization or a large negative bias), then `ReLU(z) = max(0, z) = 0` for all of them, and the ReLU derivative `(z > 0)` is 0 everywhere too. Since gradient descent updates depend on that derivative, the gradient flowing back through this neuron is always exactly 0 — its weights never update again, so it's permanently "dead," regardless of future inputs.

4. Chain: `∂L/∂W1 = ∂L/∂a2 · ∂a2/∂z2 · ∂z2/∂a1 · ∂a1/∂z1 · ∂z1/∂W1`. In the code: `∂L/∂a2 · ∂a2/∂z2` together simplify to `dz2 = (self.a2 - y) / n` (the BCE+Sigmoid combined derivative); `∂z2/∂a1` corresponds to `self.W2.T` (used in `da1 = dz2 @ self.W2.T`); `∂a1/∂z1` corresponds to `relu_derivative(self.z1)` (used in `dz1 = da1 * relu_derivative(self.z1)`); and `∂z1/∂W1` corresponds to `X.T` (used in `dW1 = X.T @ dz1`).

With only 2 hidden neurons, the model usually still learns *something* but the decision boundary tends to be visibly cruder/blockier — it may misclassify more points near the moons' overlap region. This happens because 2 ReLU neurons can only combine into a very limited number of linear "folds" in the decision surface; the two-moons dataset needs a genuinely curved boundary, which requires enough hidden units (and their combined piecewise-linear regions) to approximate that curve well. Both the NumPy and PyTorch versions should show the same qualitative degradation, since they implement the same math.

6. Training with MSE instead of BCE for this Sigmoid-output binary classifier typically converges noticeably *slower*, especially early on when predictions start far from the true label — this matches the theory's explanation: BCE's gradient collapses to a clean `(ŷ - y)` term that stays large when the model is very wrong, while MSE's gradient includes an extra `sigmoid'(z)` factor that shrinks toward 0 when the sigmoid is saturated (very confident but wrong), weakening the learning signal exactly when it's needed most.
